Lancetta 0.13.0

Release notes

Lancetta now shows where it reads each agent from and lets you choose which Codex it reads. On macOS 27 the Overview window pulls to refresh, and the whole app moves.

Sources

Settings › Sources says where each agent is read from.

  • Codex: the binary Lancetta runs, how it was found and the version it answers, then every place Lancetta looked, in order, with what was there. An agent that is installed and not found no longer looks exactly like one that is not installed. When Codex isn't found, its card says so and opens this pane.
  • Claude, which has no binary: whether Lancetta reads your account or the status-line file, and when that file was last written.

You can choose the Codex to read by hand, three ways: Choose…, a pasted path, or Use beside a second copy the search found. The path is kept as you chose it, so Homebrew's /opt/homebrew/bin/codex stays valid across upgrades. A binary you choose is the only one Lancetta runs, for the quota and for a free reset alike, until you clear it.

Pull to refresh

On macOS 27, pull any pane of the Overview window down to read it again, as in Mail. Each pane reads what it shows:

Pane What a pull reads again
Overview the quotas, the processes, the token history and Last week
Limits the quotas and the processes
Usage the token history
Processes the processes alone

The spinner holds for a couple of seconds and lets go while the reading finishes. A second pull while the first is still out waits for it rather than starting over.

It moves

The panel and the window now move:

  • cards land;
  • figures roll up;
  • bars fill and the chart's columns grow;
  • a refresh presses the cards it reads again, without ever rolling a number back through zero.

With Reduce Motion on, everything simply appears.

The current macOS look

Settings and the window now draw the controls of the macOS they run on. On macOS 27 they used to be drawn as on macOS 15: the old switches, the grey toolbar band and the old window buttons. The app told macOS it was built for 15, and macOS believed it.

Smaller things

  • Last week and the pace line follow the Codex account you are signed in to, so switching accounts no longer mixes the two. A change of Codex binary also forgets the old account's free-reset credit and any retry still on its way.
  • A Codex installed with npm now starts when Lancetta is opened from the Finder. That Codex is a script that needs node, which a Finder launch cannot see. Lancetta now runs it with the folder it was found in on its path, where npm normally keeps node beside it.
  • Fewer shells.
    • A Codex that only your login shell knows is remembered for ten minutes instead of being asked for at every read.
    • A shell that does not answer in time is stopped.
  • The report names no account. Paths in the report you copy from "What went wrong" no longer carry your macOS user name.
  • Refresh now's spinner stops when its own reads are back, instead of waiting on a scheduled read that happened to be out at the same time.
  • Waits keep the right time. A sleep in the middle of a read no longer cuts it short, and a clock set back no longer holds one up.

Install

  1. Download Lancetta-0.13.0.dmg
  2. Open the DMG and drag Lancetta into Applications
  3. Launch normally — the app is signed with Apple Developer ID and notarized by Apple

Requirements

macOS 15.0 or later.
