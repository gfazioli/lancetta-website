Lancetta 0.66.0

Release notes

Settings, as System Settings moves

  • The window's title is now the name of the pane you are on, beside the back and forward arrows, as in System Settings. On an agent's page it is the agent's name, so the Window menu says where you are.
  • The sidebar no longer has a hide button: it is how the window is navigated.

The keyboard

  • Back and Forward have keys of their own, ⌘[ and ⌘], in the Go menu, under the window's panes on ⌘1 to ⌘6.
  • Edit › Search (⌘F) puts the cursor in the Settings search, to find a setting by name.
  • On macOS 27 a shortcut fires only from a menu, which is why these are menu items. The menus show each one in your keyboard layout's own keys: on an Italian keyboard, Back reads ⌘ò.
