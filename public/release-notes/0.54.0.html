Lancetta 0.54.0

Release notes

Maintenance checks where Codex has worked too, and counts skills the way Claude Code lists them.

Where Codex has worked

  • Maintenance now checks the repositories you have worked in with Codex over the last 30 days, as well as those of Claude Code: one you only open with Codex gets its checks too.
  • A linked worktree counts as its main checkout, and scratch folders (temporary ones, background jobs', the chats Codex's desktop app starts in Documents) are left out.
  • The line Maintenance shows while it looks says where it is looking.

Fixes

  • A SKILL.md inside a skill's own folder, part of what the skill carries with it, is no longer counted as one more skill, nor warned about as one. A folder named synced, which is claude.ai's, is no longer taken for a skill either.
  • After you choose another Codex in Settings › Sources, Fix with Codex starts the one you chose, even when a check was still running as you changed it.
