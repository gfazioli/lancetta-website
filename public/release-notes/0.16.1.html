Lancetta 0.16.1

Release notes

Three fixes: Reclaim, a free reset that wasn't one, and Codex found somewhere else.

Reclaim reads the whole folder

A background tree in a folder with " -- " in its name is no longer taken for one whose folder is gone. Lancetta found each tree's folder in the process list, which joins a command's arguments with spaces and quotes nothing. A folder named like that was read cut short, as a path that does not exist, and that is exactly what makes a tree an orphan. So Reclaim could stop a session that was still working there, and the check made just before stopping it read the folder the same way.

  • Each folder is now read whole. Lancetta reads every background tree's arguments from macOS one by one, so a space or a " -- " in a name stays part of it.
  • A folder it cannot read is never gone. A tree whose arguments cannot be read has no folder as far as Lancetta knows, and an unknown folder is never treated as missing.

No free reset from another account

Signing in to another Codex account while Lancetta was not running no longer announces a free reset. Lancetta remembers how many reset credits it last saw, so that a credit granted while it was closed is still announced. That count did not say which account it belonged to, so the new account's credits were compared with the old one's, and any difference was announced as a grant. The count now carries which account it belongs to, and another account's credits are counted from where they are.

Codex in another place, same account

If Codex turns up in another place on your Mac, Lancetta now keeps what it knew about your account, as long as Codex names the same one: its readings, the free-reset count and last week's recap. Before, any new path was treated as another account and all of that started over.

Install

  1. Download Lancetta-0.16.1.dmg
  2. Open the DMG and drag Lancetta into Applications
  3. Launch normally — the app is signed with Apple Developer ID and notarized by Apple

Requirements

macOS 15.0 or later.
