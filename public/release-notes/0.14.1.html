Lancetta 0.14.1

Release notes

Text the right way up, a more careful Reclaim, and one Codex account at a time.

Text the right way up

On 0.14.0 a card in the main window could show its text upside down. If a card left the window and came back while the window was closed, which a moment when Codex could not be read is enough for, its title, labels and buttons were mirrored top to bottom when you opened the window again, and stayed that way until you relaunched Lancetta. The figures looked right, because they redraw as they change.

Cards are now drawn the right way up however they come back.

A more careful Reclaim

  • Reclaim looks again just before it stops anything. The list it shows can be minutes old by the time you confirm, so it checks each process again at that moment and stops it only if it is still the same orphan.
  • A folder Lancetta is not allowed to open is no longer taken for a deleted one. A session working in a protected folder could be listed as an orphan; it is now left alone.
  • One Reclaim at a time. The buttons stay off while one runs, and the report after it counts what is gone and what is still running.

One Codex account at a time

Signing Codex in to another account is now noticed even when it is the same Codex. The previous account's free resets and alerts are no longer shown for the new one.

Install

  1. Download Lancetta-0.14.1.dmg
  2. Open the DMG and drag Lancetta into Applications
  3. Launch normally — the app is signed with Apple Developer ID and notarized by Apple

Requirements

macOS 15.0 or later.
