Lancetta 0.50.0

Release notes

Lancetta now tells you what to do, not only how much is left.

Suggestions, first

The panel and the window open with suggestions, worked out on your Mac from the readings Lancetta keeps. Each one says what is happening, what to do about it, and what it rests on, so you can check it before you act:

  • When an agent is about to stop: when, how long it would then wait, and what helps — a lower effort (read from the agent's own settings), a lighter model for routine work, a free reset you hold, or the other agent while it has room.
  • When a week is running out early, days before it would.
  • When a window is about to reset with most of it unused: spend it, start the long task now.
  • When a free reset is about to lapse, what Maintenance found in your agents' setup, and processes nobody can use any more.

The ones that cannot wait (an agent stopping within the hour, room about to go unused, a free reset about to lapse) also arrive once as a notification, and a click opens them in the window. When nothing needs changing, Lancetta says so.

Maintenance

A new pane for the files your coding agents read before every session: CLAUDE.md, AGENTS.md, rules, skills, commands, settings and memory, in each repository Claude Code has worked in and the folders above it.

  • What loads at each start, measured against the size at which Claude Code warns.
  • 20 checks, each saying why it matters.
  • Five kinds of fix that need no choosing are shown line by line before they are applied, and applied whole or not at all. The rest opens in Claude Code, in plan mode, with the prompt written for you.
  • Files no agent uses can go to the Trash, and Claude Code's finished background sessions can be removed.
  • It has its own page in Settings.

A window of cards

  • Under its suggestions, the panel shows the window in brief: a card per agent, Usage and Maintenance, each opening in place.
  • Every pane of the window is a deck of cards that open in place.
  • The window opens where you left it, at 1200 × 800 the first time.

Under the notch

An agent that has stopped, or will within the hour, turns its bar red, and the open island ends with the same suggestion as the panel.

Smaller things

  • Small text in the panel and the window is easier to read, and closed cards no longer look disabled.
  • Settings › Updates shows whether Lancetta really checks for updates on its own.
  • Settings › Notifications says where a click on a notification takes you.

Install

  1. Download Lancetta-0.50.0.dmg
  2. Open the DMG and drag Lancetta into Applications
  3. Launch normally — the app is signed with Apple Developer ID and notarized by Apple

Requirements

macOS 15.0 or later.
