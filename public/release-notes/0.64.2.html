Lancetta 0.64.2

Release notes

Fixes that stay inside the repository

  • Maintenance offers fixes for the agent files it finds in your repositories, such as keeping a personal file out of git or giving Gemini CLI a settings file. A repository can make its .gitignore, or its .gemini folder, a link to a file or a folder somewhere else on your Mac, as a project unpacked from someone else's archive could. Applying the fix then wrote to the place the link pointed to, outside the repository, and the change stayed there. Maintenance now looks for such a link and leaves that fix out, so a fix only ever writes inside the repository it is about.

A damaged .git file stays small

  • Maintenance reads each repository's .git file to learn where its checkout lives, and it read that file whole: a damaged one that claimed to be gigabytes long, while taking no room on disk, filled memory just as fast. It now reads it the way it reads every other file, up to a few megabytes.
