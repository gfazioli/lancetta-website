Lancetta 0.69.0

Release notes

Lancetta opens at login again

  • If Lancetta had stopped opening when you log in, it opens again from the next login. Another copy of Lancetta, such as one run from a download, could take Open Lancetta at login over: now only the copy in your Applications folder changes it, and a copy run from anywhere else says to move it there.

A new About

  • About Lancetta shows the support page every Undolog app shares, with the sponsors and the other apps.
  • It opens by itself once when the sponsors or the suggested apps change, never over a full-screen window.

Install

  1. Download Lancetta-0.69.0.dmg
  2. Open the DMG and drag Lancetta into Applications
  3. Launch normally — the app is signed with Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later.
