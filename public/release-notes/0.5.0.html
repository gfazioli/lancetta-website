Lancetta 0.5.0

Release notes

Lancetta speaks first, about what the menu bar cannot show.

It speaks first

Notifications for what the percentage on your bar cannot say. A window that will run out before it resets — at this pace it is spent by tomorrow afternoon, and it does not reset until Thursday — an agent that has nothing left, one that is ready again, and a reading that has stopped moving while looking live. Each is said once, at the moment it changes, never on launch. A sound only for the two moments you are not looking at a screen: the work stopping, and the work being possible again.

Alerts and suggestions are separate switches, and each agent has its own: you can have them for Codex and not for Claude. Clicking any notification opens the Limits pane. macOS asks for permission the first time there is something to say, not at launch.

The Claude route, from two Macs

Refresh now no longer puts the login-keychain dialog up. When Claude Code has renewed its sign-in, the card says so and Reconnect is the one button that asks macOS — a manual refresh landing on an expired grant was where that dialog had moved to. Every sentence that ends in a keychain read now names that click.

A Claude card still read through the status-line file says so, and offers the account beside the number. That file moves only while a Claude Code session is open, which is why Refresh now could not move it.

Smaller

  • The Updates pane names the build number, as About and the update prompt do.
  • A reset that drifts inside its window is no longer read as a new window, which kept records out of the series the pace line reads.

Install

  1. Download Lancetta-0.5.0.dmg
  2. Open the DMG and drag Lancetta into Applications
  3. Launch normally — the app is signed with Apple Developer ID and notarized by Apple

Requirements

macOS 15.0 or later.
