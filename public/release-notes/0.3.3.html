Lancetta 0.3.3

Release notes

A patch for the moment an agent can’t be read: the menu says so in one sentence, a window says why, and older Codex CLIs are spoken to in their own shape.

What changed

  • A fault is a red row, not an error dump. When an agent can’t be read, the menu shows one sentence in red and Why, and what to do…. Before, the Codex card could print the error as it arrived “{ code = "-32600"; message = "Invalid request…" }” which told the developer everything and you nothing.
  • “What went wrong” names the code, the cause and the fix. Every way a card can fail has a code (CODEX-1 to CODEX-6, CLAUDE-1 to CLAUDE-11, APP-1) with a likely cause and what to do, beside the raw evidence. Copy report puts the versions, which Codex answered and one line per agent on the clipboard, ready for an issue. The same list is at lancetta.app/docs/troubleshooting.
  • Older Codex CLIs work again. A Codex CLI before 0.153 refused Lancetta’s rate-limits request; Lancetta now retries in the shape it understands and remembers.
  • The bar’s rotation no longer starts over on every refresh. Each poll re-armed the rotation timer, which stretched the turn of whichever agent was up at that moment by up to a whole interval. The bar now keeps its pace unless a cell actually changed.
  • Lancetta keeps a log. Every read records its outcome under app.lancetta; the report carries the command that shows it.

Situations that are not faults (Codex not installed, Claude Code not signed in, a pause asked for by the account) stay the calm sentences they were.

Install

  1. Download Lancetta-0.3.3.dmg
  2. Open it and drag Lancetta into Applications
  3. Launch it normally — signed with an Apple Developer ID and notarized by Apple

Already on 0.3.x? The updater offers this one.

Requirements

macOS 15.0 or later, Apple silicon or Intel.
