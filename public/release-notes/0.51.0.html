Lancetta 0.51.0

Release notes

Maintenance can hand a fix to Codex now, and the panel lost its footer.

Maintenance: Codex can fix it too

A finding that needs a judgement can now go to Codex as well as Claude Code.

  • The button names the agent the file belongs to: Codex for an AGENTS.md or for Codex's own size limit, Claude Code for its own files. Its menu offers every agent installed, and for a file that is neither's it remembers the one you last picked.
  • Codex opens in Terminal in the file's repository, with the prompt written for you, and is asked to propose before it edits, in a sandbox that writes only in the repository and the file's own folder.
  • It is the same Codex Lancetta reads, the one you picked in Settings › Sources included.

A tidier panel

  • No footer. A card opens the window, so Open Lancetta… and Quit no longer take a row at the bottom.
  • The gear opens a menu: Open Lancetta…, Settings…, Check for Updates…, About Lancetta and Quit Lancetta. It sits in the corner, with the pin beside it, and drops its menu inside the panel. ⌘O, ⌘, and ⌘Q still work.
  • A right-click on the menu-bar item opens the same menu, with Refresh Now at the top.
  • With every agent switched off, the panel points you to Settings › Agents.
