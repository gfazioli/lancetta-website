Lancetta 0.53.0

Release notes

Maintenance makes every fix that needs no choosing in one go, and finds the hooks and servers that can't start.

Fix All

Every fix that needs no choosing, in one preview.

  • Fix All sits beside Copy Findings at the top of Maintenance. It lists each fix with the file it changes, then every line it writes.
  • Apply makes them one after another, each whole or not at all. One that can no longer be made leaves the others made, and the notice says which were not and why.
  • Nothing else is offered between an Apply and the scan after it.

Hooks and servers that can't start

  • Maintenance now checks the hooks, the status line, the helpers your settings run and the MCP servers in a .mcp.json: a program that isn't there or can't run, a path with a space left unquoted, a variable nothing fills in where no shell runs.
  • Three new fixes: quotes round the path (the settings file keeps its comments and layout), execute permission for a script that names what runs it, and a variable written the way Claude Code fills it in. Each is offered only when the program would then start.

The skill listing and the memory index

  • Each place's skills and commands are checked against the room Claude Code gives their listing, sized by the model that place's settings name: past it, the ones used least lose their description.
  • A memory index nearing the part that loads is a suggestion before it becomes a warning.

Fewer false findings

  • Rules in a workspace of ignored repositories, paths into what git ignores, placeholders and generated blocks no longer raise one.
  • The prompt handed to Claude Code or Codex asks it to write in the language each file is already written in.
