Lancetta 0.63.1

Release notes

Your Claude Code sign-in stays in the keychain

  • Each reading of your Claude account left a copy of the request, sign-in included, in Lancetta's cache folder on disk. The request now keeps nothing on disk and goes only to the address it is meant for, and the copy an earlier version left there is removed when Lancetta starts.

Repositories you did not make

  • A repository's own git settings can no longer start a program while Maintenance looks at it, so a project unpacked from someone else's archive, history and all, runs nothing when you open the panel. A fix that stops tracking a personal file switches those programs off too, and declines what it cannot do safely: a program whose name it cannot pass along, or another repository checked out where the file should be.

Smaller fixes

  • Lancetta now loads only code signed by Apple or by its developer.
  • lancetta usage --json leaves your account's name out of the paths in the problems it lists, and lancetta statusline no longer stops on a document edited by hand.
