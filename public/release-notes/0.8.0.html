Lancetta 0.8.0

Release notes

Lancetta 0.8.0 — the menu bar says where you stand, all day rather than at the end.

A lamp beside every agent

There is now a small glass bead between an agent’s mark and its numbers, and it is always there.
green up to half the window spent — work
amber past halfway — still yours, but it is going
red near the end — finish what you are on
black, red edge refused, or nothing left. Unusable until it comes back

A window nobody has managed to read yet shows a grey bead rather than a green one. An unknown is not an empty quota, and telling the two apart is the reason this app exists.

It replaces the red sign that used to mark a blocked agent. That sign only ever appeared once you were already blocked — so for the whole of the day when the answer could still change what you did, the menu bar had no colour to give you, and then it had one at the single moment nothing could be done with it.

The bead reads what is spent, whichever way round you asked to see the number. If your bar shows what remains, 3% on screen is a red lamp, not a green one.

A blocked agent looks like the others

A refused agent used to lose its percentage entirely: 19% · ↻83m beside ↻25h19m, two different shapes in one bar at the moment you are scanning it fastest. It now reads 100%, in the same shape as every cell beside it.

The number is not the last reading. Your account has said there is nothing left, which is more recent than whatever the last check measured. And it follows the fields you picked, like any other cell: switch the percentage off in Settings and a blocked agent has none either.

Also

  • Copy report keeps its name in the What went wrong window. On the default window the button had been truncated to Copy rep… — the one control that window exists to offer.
  • The Troubleshooting page on the site now shows that window instead of only describing it.

Install

  1. Download Lancetta-0.8.0.dmg
  2. Open the DMG and drag Lancetta into Applications
  3. Launch normally — the app is signed with Apple Developer ID and notarized by Apple
