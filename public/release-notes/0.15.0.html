Lancetta 0.15.0

Release notes

The pace line now tells you how long you can keep going like this, and the early-warning notification and the window it opens finally say the same thing.

How long you can keep going

The line under each bar says when you would run out, in amber: at this rate you run out in 2h00m. It works from the last hour or so of your readings, pauses included, and it appears only when that moment comes before the window resets and within a few hours. Slow down and it moves out; stop and it goes away. That is what at this rate means.

  • One row says it: the window that would stop you first. When the weekly window would run out before the 5-hour one, the 5-hour row keeps quiet, and the other way round. Nothing is said once you are already stopped.
  • A model's own weekly limit says its own, under its row, so a week of one model running out shows up while there is still time.
  • Otherwise the line says what the window has used and for how long: 60% in 2h00m, or 93% in 6d19h, with the weekly window now read in days and hours.
  • The old projection is gone. At this pace 96% by reset only restated the bar, and full by Wednesday afternoon spread one afternoon's work over the nights before it.
  • Limits says what the line rests on: the rate, the time it was measured over, and how many readings of the window there are.

The notification and the window agree

"Will run out early" still reads the window's average so far, which is the right rate for a warning days ahead, since the days ahead hold nights and pauses too. When it fires, Limits now shows the same sentence under that window's line: At this pace it is spent by Tuesday morning, and it does not reset until Thursday afternoon. With Only when a window would run out early on, the line stays visible in that case too.

Install

  1. Download Lancetta-0.15.0.dmg
  2. Open the DMG and drag Lancetta into Applications
  3. Launch normally — the app is signed with Apple Developer ID and notarized by Apple

Requirements

macOS 15.0 or later.
