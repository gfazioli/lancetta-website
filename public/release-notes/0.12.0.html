Lancetta 0.12.0

Release notes

Two new ways to read what Lancetta already keeps — every agent side by side, and the week that just ended — and a command line for anything else that wants the numbers.

Both agents, side by side

The Overview's Quota Used card now draws every agent on one row: its 5-hour and 7-day windows next to each other, each with the figure, the bar, the time to the reset and, when there is something worth saying, where the window is heading at this pace. A model with a weekly limit of its own is drawn under its agent.

It gives the numbers and never a verdict. Whether one agent can take over what the other is in the middle of is yours to know, so the card never says which one to use.

Last week

Under it, a Last week card: the week that just ended, for each agent — each agent's own weekly window, not a calendar week, so Claude's and Codex's lines each say which days they cover.

  • Weekly — when the window ran out and when it was back, or the highest reading of it, and when the provider emptied it early if it did.
  • 5-hour — how many 5-hour windows reached 100%, and how long they held you up in all.
  • Not seen — how much of the week had no reading at all. A night the Mac spent asleep is a gap, never a zero.

Once there is a whole week before it, one line compares the two. Until Lancetta has watched a week from its start, the card says when the first whole one ends instead of passing a few days off as a week. It says what happened, never what you should have done about it.

A command line

Lancetta usage --json prints what Lancetta last read for each agent as one JSON document — for a tmux status line, SketchyBar, a desk display, or a script.

It never reads an agent itself: no keychain, no dialog, no request to either account. The app rewrites the document after every read, every reading carries its own observedAt, and the document its writtenAt, so a consumer can tell a held number from a fresh one. Run from a shell, the binary never starts a second copy of the app. The document, field by field, and the exit codes: lancetta.app/docs/command-line.

Smaller things

  • A locked keychain is no longer a click. When the keychain holding Claude Code's sign-in is locked, the card says so and Lancetta reads again by itself once you unlock it; Refresh now tries straight away.
  • Numbers follow your region. Token counts, the Usage card's change and the pace rate use your region's format (351,6M in Italy, 351.6M in the US), and every surface writes them in the digits 0 to 9, whatever numbering system the region uses.
  • Counting down, the pace line speaks in what is left. With Count down what is left on: 40% left, 2h00m in · at this pace empty by 11:20, 1h40m early. The free-reset question does the same.
  • A refused Claude sign-in no longer slows the next recovery. An expired or refused sign-in used to lengthen the wait after the account's next pause, from seconds to minutes; and Lancetta no longer retries once a second when its own back-off and the account's pause disagreed.
  • An absurd token count can no longer crash the app. A count outside 0 to a trillion, in Codex's history or in a Claude Code transcript, is left out rather than added up.

Install

  1. Download Lancetta-0.12.0.dmg
  2. Open the DMG and drag Lancetta into Applications
  3. Launch normally — the app is signed with Apple Developer ID and notarized by Apple

Requirements

macOS 15.0 or later.
