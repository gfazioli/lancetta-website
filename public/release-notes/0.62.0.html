Lancetta 0.62.0

Release notes

A Storage card in Maintenance

  • Maintenance finds what your coding agents, and the tools they run, leave on disk that nothing uses any more: Codex installs that stopped halfway, superseded Codex server releases, unfinished marketplace updates and empty git folders, files the ChatGPT app copied out, the Xcode build caches of ended sessions, and Chrome's code-sign clones.
  • Each row says what it frees and why it can go. Nothing a running program holds is offered, and each folder is looked at again just before it moves to the Trash, where the Finder can put it back.

Checks that read what Claude Code reads

  • Two new checks: a settings file Claude Code drops without a word (a comment, a trailing comma, the wrong encoding), and a skill one folder too deep, which it never lists.
  • Your organization's policy is read the way Claude Code reads it, from a managed profile too. A policy file that would stop Claude Code from starting is flagged under a badge of its own, Organization, and hooks and servers that the settings or the policy switch off are no longer flagged.
  • The launch budget counts imports and the rules of the folders above, as Claude Code's own warning does; an import from outside a project counts only where you allowed external imports.
  • Each place's memory is found where Claude Code keeps it: a worktree reads its main checkout's, and a memory folder moved in the settings is followed.

Fixing, one place at a time

  • A skill listing past its budget offers Listing Choices…: turn off the synced skills or a plugin, or list skills by name only, each shown in full before anything is written.
  • In Launch Weight, each place shows its warnings and suggestions, and one button hands all of them to a single Claude Code or Codex session.
  • A fix never writes outside the repository on disk.

Smoother

  • Every card and row in Maintenance opens from the keyboard and VoiceOver too.
  • Cards stay still as they open and close: figures no longer count up from zero again, and an open card no longer jumps on a refresh.
