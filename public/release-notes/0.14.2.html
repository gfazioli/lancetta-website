Lancetta 0.14.2

Release notes

Update checks that run at launch, a sturdier usage history, and a few controls that no longer lag behind.

Check for updates on launch

With both update checks on, the one at launch never ran. Lancetta asked for it while the updater was still starting up, and the request was turned away, so a new version showed up only with the daily check or from Check for Updates…. The launch check now waits until the updater is ready.

A sturdier usage history

  • Two copies of Lancetta no longer lose each other's lines. Each reading is appended in a single write, so two copies writing the history at once (an installed one beside a test build) keep every line.
  • A line cut short costs that line alone. A reading half-written by a full disk used to leave the whole history unreadable; now only that line is skipped, and the next one starts on a line of its own.
  • The pace line keeps going when a reading cannot be saved, and the reading is written on a later poll.
  • A change to the Mac's clock no longer shortens or stretches the pause between reads of the Claude account.

Controls that keep up

  • Open Lancetta at login goes back to how it really is when macOS refuses the change.
  • Check for Updates… is no longer left greyed out.
  • The reading under the notch grows to show a model's own bar instead of cutting off its last row.
  • Processes and Usage are translated. The process rows read in your language, one child included, and the Usage card's caption is no longer English.

Install

  1. Download Lancetta-0.14.2.dmg
  2. Open the DMG and drag Lancetta into Applications
  3. Launch normally — the app is signed with Apple Developer ID and notarized by Apple

Requirements

macOS 15.0 or later.
