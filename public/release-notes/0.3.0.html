Lancetta 0.3.0

Release notes

Claude’s quota from your account, with one click instead of a script — and two smaller things that came along.

What changed

  • Claude Code, connected with one click. Lancetta now asks your Claude account how much is left, with the sign-in Claude Code already keeps on your Mac — the same question Claude Code’s own /usage asks, with no model in the loop, so nothing is billed. Choose Connect Claude Code’ in the menu, or under Settings — Agents — Claude; macOS asks once whether to allow it. From then on Claude refreshes on demand the way Codex does, and the card shows your plan. The sign-in is only read, never renewed: if it has expired, the card says so, and Claude Code renews it the next time you use it. The status-line route from 0.2 still works for anyone who would rather not hand the app a keychain item — nothing asks for it any more.
  • What’s New, under Help. Each release’s own notes, inside the app.
  • The icon on macOS 26 and later. The Dock was drawing a white frame around it: those versions put any icon in the old format on a plate of their own. The app now ships the format they expect. Nothing changes on macOS 15.

One sentence in About changes with the first item: one request now leaves your Mac, to Anthropic, carrying Claude Code’s own sign-in — and Disconnect stops it. The privacy page says the same.

Install

  1. Download Lancetta-0.3.0.dmg
  2. Open it and drag Lancetta into Applications
  3. Launch it normally — signed with an Apple Developer ID and notarized by Apple

Already on 0.2.x? The updater offers this one.

Requirements

macOS 15.0 or later, Apple silicon or Intel.
