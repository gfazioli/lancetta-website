Codex Sessions, in Maintenance

  • Every codex exec and codex review is saved in Codex's list like a conversation, with the thread each review runs in, and they pile up. A new card lists every session Codex keeps, newest first: what started it, the folder it ran in, when it was last active and its id.
  • Select Commands ticks the sessions commands and agents ran, never your conversations. Archive… archives them the way Codex itself does, so codex unarchive brings any of them back. Nothing is deleted.
  • A session open in a Codex window, held by a running program, written to within the hour, or whose spawned agent is any of these, is never archived: each one is looked at again just before its turn.
