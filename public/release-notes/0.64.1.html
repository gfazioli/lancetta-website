Lancetta 0.64.1

Release notes

When a program writes without end

  • Lancetta reads Codex by running it and reading what it writes. A Codex, or a program you chose for it in Settings › Sources, that wrote one endless line or logged without a pause was held in memory, as fast as it wrote, until the read gave up after up to 30 seconds. Lancetta now stops reading at 16 MB and says so with a new code, CODEX-8, listed on the Troubleshooting page, and keeps only the last whole lines of what went wrong.
  • The version check in Settings › Sources and the Sessions wall's listing stop at the same 16 MB, and the commands the Maintenance pane runs at 64 MB, room for a whole repository's list of files.
  • A steady stream of short lines could still pile up, because every line read was kept until the read ended. Lines are now let go as they are read.

Developer settings stay with developers

  • Two settings meant for development, each naming a program to run in place of Codex or Claude Code, are now ignored by the version you download. Any program running as you could set one for every app you open afterwards.
