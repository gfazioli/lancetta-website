Lancetta 0.2.1

Release notes

A universal build. If you are on an Intel Mac, 0.2.0 would not open for you — this one does.

What changed

  • Universal binary. 0.2.0 shipped with only the Apple silicon slice, while this site advertised Universal and macOS 15 still runs on Intel Macs from 2019–2020. 0.2.1 carries x86_64 and arm64, both declaring macOS 15.0 as their floor.
  • Nothing else. Same app, same features as 0.2.0 — see the 0.2.0 notes for what it does.

If you are on Apple silicon and already running 0.2.0, there is nothing here you need; the updater will offer it anyway, and taking it costs you a restart of the app.

Install

  1. Download Lancetta-0.2.1.dmg
  2. Open it and drag Lancetta into Applications
  3. Launch it normally — signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15.0 or later, Apple silicon or Intel.
