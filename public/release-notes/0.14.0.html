Lancetta 0.14.0

Release notes

Lancetta now speaks Italian, French, German, Spanish, Portuguese and Dutch as well as English, and follows the language your Mac is set to.

In your language

Everything follows: the panel, the island under the notch, the window, Settings, the alerts, What's New and the update dialogs. Weekdays and dates are written in the language of the sentence around them, so an Italian sentence names an Italian day.

There is no language setting in the app. To use another language, put it first in System Settings › General › Language & Region: macOS uses the first language on the list that Lancetta speaks.

What stays in English

What someone else reads stays in English, whatever your Mac speaks: the report Copy report puts on the clipboard, the output of Lancetta usage --json, and Lancetta's own log. A problem keeps its code in every language, so CLAUDE-8 is CLAUDE-8 in German too, and the entry on the website's Troubleshooting page is the same one.
