# Getting Started

Lancetta tells you when and how to use your coding agents: when to push on, when to slow down, what to switch to, and what to fix in the files they load at every start. For that it needs to read each agent's quota, which costs nothing, and this page is about wiring that up.

## Requirements

- **macOS 15 (Sequoia) or later.**
- **Codex, Claude Code, or both.** Lancetta shows a card per agent it can read; an agent you do not have installed simply does not appear.

## Install

Download the DMG, drag Lancetta to Applications, and launch it. It puts an item in your menu bar and, at rest, **nothing in the Dock** — the menu bar is where it lives.

There *is* a window, opened with **Open Lancetta…** (⌘O) from that menu, but the app does not need it: closing it does not quit anything, and the menu-bar item is always the way back. A Dock icon appears while that window is open and goes with it, because a window needs its app to be a normal one; [one switch](/docs/settings#general) keeps the icon there permanently if you prefer.

**Open Lancetta at login** is a switch in the same place, off by default.

On first launch it looks for each agent it knows about. It does this itself because **a GUI app inherits almost no `PATH`**: launched from the Finder, a Mac app sees `/usr/bin:/bin:/usr/sbin:/sbin` and neither agent is in any of those. Lancetta looks in the places these tools actually install to, and falls back to asking your login shell. If it still does not find one, **Settings › Sources** lists every place it looked and lets you point it at the binary yourself.

## Codex

Nothing to do. Codex can be asked how much quota is left and will answer, so Lancetta asks it — on the schedule you choose in Settings, and again whenever you pick **Refresh now**.

That question costs no tokens. It is an account read, not a model turn; see [How it reads each agent](/docs/how-it-reads).

## Claude Code

One click. Open the panel and, under Claude, choose **Connect Claude Code…** (it is also in Settings › Agents › Claude). Lancetta reads the sign-in Claude Code keeps on your Mac and asks your Claude account how much is left — the question Claude Code's own `/usage` asks. It reads that sign-in the way Claude Code itself does, through macOS's own `security` tool, so there is normally no dialog to answer.

Claude Code rewrites its sign-in every time it renews it, and Lancetta reads the new one by itself: no Reconnect, no dialog. If your login keychain is locked, Lancetta reads nothing and says so, and tries again by itself at the next reading once you unlock it (Keychain Access does); **Refresh now** tries straight away. If the route is closed for any other reason, Lancetta has to ask macOS directly, and it only does that when you choose Connect: a background read never raises a dialog, and neither does Refresh now. The card offers **Reconnect** instead; choose **Always Allow** when macOS asks.

What that click does, and does not do:

- **It reads the sign-in; it never renews it.** Claude Code renews its own sign-in whenever you use it. If it has expired, the card says so, and once Claude Code has renewed it Lancetta reads the new one by itself.
- **One request, to Anthropic, the same one Claude Code makes.** Nothing else is sent, and no model is involved, so nothing is billed.
- **Disconnect**, in Settings › Agents › Claude, stops it.

If you would rather not hand Lancetta a keychain item, there is an older route that connects nothing: a line in your status-line script writes the numbers to a file, and Lancetta reads the file. It is spelled out in [How it reads each agent](/docs/how-it-reads#the-other-route), with its two limits. If Claude was already being read through that file when you installed this version, nothing changes until you ask: the card carries the numbers as before, a line saying where they come from, and the Connect button beside it.

## Read the panel

Click the menu-bar item. The panel opens on **what to do**: up to three suggestions, the most urgent first and open, each with what helps and what it rests on. A new install has no history yet, so a suggestion about your pace waits until Lancetta has watched a window move for half an hour or so; the others can appear from the first reading. With nothing to suggest, one line says so.

Under the suggestions there is a card for each agent and for each pane of the window. Click an agent's card for the plan the account is on and a row per window: the percentage used, a bar, and the time that window resets.

## Your language

Lancetta speaks **English, Italian, French, German, Spanish, Portuguese and Dutch**, and follows your Mac's language by itself — there is no language setting in the app. To run it in a different one, reorder your preferred languages in **System Settings › General › Language & Region**: macOS uses the first one on the list that Lancetta speaks.

All of it follows: the panel, the island under the notch, the window, Settings, the alerts and the update dialogs, with weekdays and dates written in the language of the sentence around them. A problem keeps its code in every language — CLAUDE-8 is CLAUDE-8 in German too — so the entry on [Troubleshooting](/docs/troubleshooting) is the same one whatever your Mac speaks.

## And then the rest of it

- On a MacBook Pro, the same reading sits under the notch, turns red when an agent has stopped or will within the hour, and opens on the same suggestion as the panel when you point at it — [The Notch](/docs/the-notch).
- **Open Lancetta…** (⌘O) gives you every suggestion, usage over weeks, both agents in detail, and the background processes the agents have left running — [The Window](/docs/the-window).
- The window's **Maintenance** pane checks the files your agents read before every session, and fixes what needs no choosing once you have seen the change — [Maintenance](/docs/maintenance).
