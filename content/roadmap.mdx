# Roadmap

Nothing here is a promise with a date on it. It is the order the work is being done in, and — more usefully — **what each step has to do before it counts as finished**.

## v0.2 — the quota, and rather more than the quota

*Shipped 2026-09-18 — the first release.*

The point of this version was narrow and concrete: stop reading a quota number off a terminal status line. That cannot be done with one agent, because the status line shows both — so both quota cards ship together or the first version does not achieve the one thing it exists for.

- Codex quota, with binary discovery that works from a Finder launch (where a GUI app inherits almost no `PATH`)
- Claude Code quota, from the status-line payload, with the card honest about its age when nothing has rendered
- The menu-bar item: alarm first, percentage second, age visible when a source falls behind, and configurable per agent
- Per-agent identity — a colour and the vendor's own mark, carried by the agent rather than hardcoded in the menu, so a third agent is one new file
- The order the agents take, set once and obeyed by every surface
- The island under the notch
- Settings, About, and a Check-for-Updates that says what state the build is in

**Done when** it runs launched from the Finder — not from a terminal that has a `PATH` — both cards agree with what each tool reports directly, and a working day passes without anyone looking at the status line.

**Two things arrived early and are in this version rather than the next two.**

**The processes they leave behind** — the reaper: count, total footprint, orphan count, and a **Reclaim** that lists what it will stop *before* stopping it, in the menu and in the window. It was planned for a later version and is built. It reproduces the twelve-of-fourteen result with zero live trees touched, and it is driven against decoy processes in an automated self-test rather than against the machine it is running on. See [The processes they leave behind](/docs/memory).

**The window** — Overview, Usage, Limits and Processes, with the daily token series drawn as a chart. The series was planned as half of v0.5 and turned out to be free: Codex already keeps it and gives it away. See [The Window](/docs/the-window).

And with them, three things that came along with turning Lancetta into a real application bundle rather than a bare executable: **open at login**, a switch to **keep the icon in the Dock**, and the **updater** itself — the framework, the three controls and the feed address. What is not there yet is anything at the other end of that feed, which is the next entry.

## v0.3 — it speaks first

A percentage on an icon is passive: it rewards looking. The value is in the two moments the app can speak first.

**Alarms** — a window refused you, a threshold was crossed, or a source has gone quiet past its own cadence. A frozen number is the original defect of this whole project, so its silence is itself an event.

**Advice** — nothing changed, but the shape of the next hour did. *"The 5-hour window resets in 12 minutes and you are at 33% — the remaining 67% goes with it."*

The advice half ships only if the reset observations collected from v0.2 onward come back as a step function. If they come back as a slope, that feature is deleted rather than softened.

## v0.4 — everyone else's Mac

The discovery UI and the Sources pane. This is the version where the app stops assuming one machine, and it is a bigger step than it looks. The consenting Claude step this entry used to promise is already one click and a macOS dialog, not a script.

Half of what this entry used to describe arrived early: v0.2 ships signed, notarized and downloadable, so the updater already in the app has a feed with something in it.

## v0.5 — reset credits

Redeeming a Codex reset credit from the menu, with every safety rule an irreversible action needs.

## Not planned

**Asking a model how much quota is left.** It is the easiest source to write and it costs tokens on every poll. It is the one route this app will never take — see [How it reads each agent](/docs/how-it-reads).
