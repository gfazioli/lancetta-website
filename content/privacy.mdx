# Privacy

Lancetta has no account, no server and no telemetry. **Nothing you do in it leaves your Mac.**

## What it reads

- **Codex** — an account read, on your machine, over the agent's own local interface. It returns your rate-limit percentages, reset times and plan, and — separately, when the window is open — your token totals per day. It does not return, and Lancetta does not read, the contents of any session.
- **Claude Code** — one file on your disk, written by your own status-line command, holding the rate-limit block and the time it was observed. Lancetta does not read your transcripts, your prompts or your projects.
- **Your plan** — read from the account metadata the agent already keeps locally.
- **The process table** — the same list `ps` gives you, to find the background trees the agents have left running. It reads their command lines, which is where the working directory each one was started for lives. That directory is shown to you in the window; it is never sent anywhere, because nothing is ever sent anywhere.

## What it does

One thing in this app is not read-only: **Reclaim** stops background processes. Three rules bound it, and all three are in the code rather than in this paragraph:

- only a Codex broker **whose working directory no longer exists** is ever a candidate — one whose directory is unknown is never treated as gone;
- it **shows you the list first**, and the confirmation puts Cancel on the default key;
- it signals the broker, which closes its own tree. It does not touch anything else.

## What it writes

Your own preferences — the refresh interval, the colours and order you gave the agents, which ones are hidden, what each one shows in the menu bar, the notch switch, and whether you count up or down — in the standard macOS preferences location for the app. Nothing else.

## What it sends

Nothing. There is no analytics call, no crash reporter, no update ping in v0.1. When automatic updates arrive in v0.4 they will fetch a signed feed, and that fetch will be the only outbound request the app ever makes.

## Why reading costs nothing

Not a privacy point exactly, but it is usually the next question: Lancetta never sends a prompt to a model to find out how much quota is left. That would be a model turn, it would cost tokens on every poll, and it would send something. See [How it reads each agent](/docs/how-it-reads).

## This website

The site records anonymous page-view analytics through its host, and nothing else. There is no sign-up, no newsletter form and no third-party tracker.
