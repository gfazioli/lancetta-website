# Privacy

Lancetta has no account, no server of ours and no telemetry. **Nothing you do in it is reported to anyone**; the few requests it makes are listed under [What it sends](#what-it-sends).

## What it reads

- **Codex** — an account read, asked of the Codex CLI on your machine over its own local interface; the CLI fetches the figures from OpenAI with its own sign-in. It returns your rate-limit percentages, reset times and plan, how many free resets the account holds (and, once per new count, what each is called and when it lapses), and — separately, when the window is open — your token totals per day. It does not return, and Lancetta does not read, the contents of any session.
- **Claude Code** — once you connect it, the sign-in Claude Code keeps in your keychain, read and never renewed (the refresh token in the same item is never kept or used), and with it one account read: your rate-limit percentages and reset times. Or, if you set that up instead, one file on your disk written by your own status-line command.
- **Claude Code's transcripts, for the token chart** — the files Claude Code keeps under `~/.claude/projects`, searched for the usage block on each reply. Lancetta keeps the message's id, its time and its token counts, and nothing else: the text of your prompts and answers is never extracted, stored or sent. Only the files that changed since the last look are read again.
- **Your plan** — from the same account reads, or, when Claude Code is followed through its status line, from the account metadata Claude Code keeps on your Mac.
- **The process table** — the same list `ps` gives you, to find the background trees the agents have left running. It reads their command lines, argument by argument, which is where the working directory each one was started for lives. That directory is shown to you in the window; it is never sent anywhere.
- **Your agents' instruction files, for [Maintenance](/docs/maintenance)** — CLAUDE.md, AGENTS.md, GEMINI.md, rules, skills, commands, subagents, settings and memory, in each repository Claude Code has worked in and the folders above it, in `~/.claude`, `~/.codex` and `~/.gemini`, and your organisation's managed CLAUDE.md in `/Library/Application Support/ClaudeCode` when there is one. Which repositories those are comes from the transcripts under `~/.claude/projects`, of which it reads only the folder each session started in. It runs `git` in those repositories to know what is committed, and asks your own Claude Code (`claude agents`) for the background sessions it has finished with. The files are read to be counted and checked, on this Mac; what is in them goes nowhere unless you copy the findings or hand them to Claude Code.
- **The effort your agents are set to, for the [suggestions](/docs/suggestions)** — `effortLevel` in `~/.claude/settings.json` and `model_reasoning_effort` in `~/.codex/config.toml`, so a suggestion can say which effort it would lower. Read, never changed.

## What it does

A few things in this app are not read-only, and each one happens only after you have seen what it will do and said yes.

**Reclaim** stops background processes. Four rules bound it, and all four are in the code rather than in this paragraph:

- only a Codex broker **whose working directory no longer exists** is ever a candidate — one whose directory is unknown, or in a folder Lancetta is not allowed to look into, is never treated as gone;
- it **looks again just before it stops anything**: a broker is signalled only if it is still the same broker for the same missing directory;
- it **shows you the list first**, and the confirmation puts Cancel on the default key;
- it signals the broker, which closes its own tree. It does not touch anything else.

**Use… on a free reset** spends one of your Codex reset credits, which cannot be given back:

- it is offered only while the account says you hold one and a window has something to reset;
- the question names the credit, when each window would come back on its own and when the credit lapses, and puts Cancel on the default key;
- it is asked through the Codex CLI on your Mac, the same way every Codex reading is, and a retry after a lost answer repeats the same request instead of spending a second credit.

**A Maintenance fix** writes to your own files: an import added or corrected in an instruction file, a line at the end of a MEMORY.md, an entry in a `.gitignore` with `git rm --cached` beside it, or a new `.gemini/settings.json`. It shows every line it would add or remove before anything is written, writes only on **Apply**, and only if every file is still exactly what the preview showed; if anything fails halfway, everything it wrote is put back.

**Move to Trash…** moves a file no agent uses to the Trash, where the Finder can put it back. It is offered only for such files, and the file is read again just before it moves.

**Removing background sessions** asks your own Claude Code to do it, one `claude rm` per session, after a confirmation that names what it frees. Claude Code refuses on its own to remove a session that holds work not pushed.

**Fix with Claude Code** starts your own Claude Code in Terminal, in the file's repository and in plan mode, with a first message Lancetta wrote, through a one-time script in the temporary folder that deletes itself. From then on it is your session: Claude Code edits nothing until you approve its plan.

## What it writes

Four things, all on this Mac:

- **Your own preferences** — the refresh interval, the colours and order you gave the agents, which ones are hidden, what each one shows in the menu bar, the notch switch, whether you count up or down, and how many free resets it last saw, so that a new one can be announced — in the standard macOS preferences location for the app.
- **The series of its own readings**, in `~/Library/Application Support/Lancetta/history.jsonl`: for each reading, when it was taken, which agent, both windows' percentages and resets, the plan, the route it arrived by and the free resets held. Each line also carries a short salted hash of the account, so two accounts' series never mix; the salt is in `history.salt` beside it. Past 4 MB the series rolls over into `history.1.jsonl`. It is what the pace line reasons from, and it never leaves your Mac.
- **A cache of Claude's token counts**, `claude-usage-cache.json` beside it: per transcript file, its size and date and the tokens of each reply by day, so the chart does not re-read every transcript each time. File paths and numbers, never text.
- **The last reading of each agent**, `usage.json` beside it: what [`Lancetta usage --json`](/docs/command-line) prints — each agent's numbers, the plan, the route they came by, and the problem when there is one, whose detail can name a file in your home folder or quote the error an agent returned. Rewritten after every read; nothing reads it but that command and whatever you point at it.

Deleting that folder costs you the series the pace line learns from; the cache and the last readings are written again on the next read.

## What it sends

There is no analytics call and no crash reporter. Lancetta has never had either and will not get one.

Every request it makes is named here:

- **The Claude account read**, once you connect it: the same request Claude Code's own `/usage` makes, to Anthropic, carrying the sign-in Claude Code keeps and the app's version. It stops the moment you disconnect.
- **The Codex readings**, while Codex is shown: Lancetta asks the Codex CLI on your Mac, and the CLI fetches your rate limits from OpenAI with its own sign-in, as it does for itself. Hide Codex in Settings to stop them.
- **The update check**, which fetches a signed release feed from this website and carries the app's version. Both automatic forms of it are **off until you turn them on** in [Settings → Updates](/docs/settings#updates): a silent check when the app starts, and the update framework's own schedule, which asks you once, on the second launch. **Check for Updates Now…** makes the same request when you ask for it. When there is a new version, its notes come from this website and its download from GitHub.
- **The About window** shows a sponsor's picture, which is loaded from GitHub.

That is the whole list. There is no account, no server of ours, and nothing that reports what you did.

**Fix with Claude Code** is not on it because it is not a request Lancetta makes: it hands a prompt to your own Claude Code, which then works as it always does, with your sign-in, and sends what any session of yours sends.

## Why reading costs nothing

Not a privacy point exactly, but it is usually the next question: Lancetta never sends a prompt to a model to find out how much quota is left. That would be a model turn, it would cost tokens on every poll, and it would send something. See [How it reads each agent](/docs/how-it-reads).
